## 2. Scoring Formula & Aggregation Logic

* **Raw Part B Score:**  
  `PartB_Raw = (Competency_1 + Competency_2 + ... + Competency_N) / N`
* **Weighted Part B Score:**  
  `PartB_Weighted = ROUND(PartB_Raw * Part_B_Weight_Percent / 100, 2)`

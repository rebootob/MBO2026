# Project Context & Scope

TTMET MBO / PMS V2 is a modern Management By Objectives and Performance Management System built on Kintone for Staff and Chief levels.

## Stakeholders
- **Employee (Appraisee)**: Sets 2-10 objectives, inputs mid-year progress, conducts self-evaluation.
- **1st Manager / Appraiser**: Reviews objectives, reviews mid-year milestones, rates Year-End Part A & Part B.
- **2nd Manager / GM**: Approves objectives, conducts final calibration.
- **HR Administrator**: Manages process timeline, fiscal year rollover, master routing, and exports.

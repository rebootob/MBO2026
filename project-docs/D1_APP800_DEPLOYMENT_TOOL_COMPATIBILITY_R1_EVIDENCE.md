## 3. Deployment Tooling Incompatibilities Resolved

### A. Raw-Source String Manipulation Removed & Canonical Dist Artifacts Consumed
- **Old Incompatibility:** `scripts/kintone/deploy-delivery-sprint02.js` read raw `src/ui/hr-control-center.js` and attempted to strip `export`/`import` statements via naive string regex. Once `hr-control-center.js` statically imported `MboKintoneAuthAdapter`, the raw string manipulation left `import` statements in the unbundled string.
- **Replacement Design:** Created `validateHrccBundleArtifacts(opts)` in `scripts/kintone/deploy-delivery-sprint02.js`. Deployment tooling now directly loads and validates the reproducible canonical artifacts (`dist/hr-control-center-bundle.js` and `dist/hr-control-center.css` generated by `scripts/kintone/build-hrcc-ui.js`).
- **Validation Contract:** `validateHrccBundleArtifacts()` asserts:
  1. JS and CSS files exist and are non-empty (>0 bytes).
  2. 0 `import` and 0 `export` keywords remain in the JS bundle.
  3. Bundle includes `MboKintoneAuthAdapter` class definition.
  4. Bundle includes `resetMboPassword` implementation.
  5. Bundle passes real JavaScript syntax compilation (`new Function(jsCode)`).

### B. App800 Least-Privilege ACL Validation Helper (`assertApp800LeastPrivilegeAcl`)
- **Old Incompatibility:** The deploy script called `m.assertCreatorOnlyAcl(...)`, which required App800 to be Creator-only. This contradicted the accepted App800 least-privilege security model (`HR_ADMIN_GROUP` View-only).
- **Replacement Design:** Created `assertApp800LeastPrivilegeAcl(aclResponse, contextName)` in `scripts/kintone/deploy-delivery-sprint02.js`.
- **Validation Contract:**
  1. Technical `CREATOR` / `admin-form` authority preserved.
  2. `HR_ADMIN_GROUP`: `recordViewable: true`; all elevated rights (`appEditable`, `recordAddable`, `recordEditable`, `recordDeletable`, `recordImportable`, `recordExportable`) must be `false` (fails closed on privilege elevation).
  3. `everyone`: all application rights must be `false` / denied (fails closed if `everyone` has any permission).
- **Zero ACL Writes:** Operates as a pure readback validator. Performs **0 ACL POST/PUT/DELETE requests**.

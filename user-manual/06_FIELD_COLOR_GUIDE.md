# Visual Meaning of Field State Highlights & Indicators

## 1. ตารางความหมายของสีประจำช่องข้อมูล (Color Legend)

ระบบ MBO V2 ใช้สีช่วยในการสื่อสาร เพื่อให้ผู้ใช้งานมองเห็นทันทีว่าช่องใดสามารถกรอกได้ ช่องใดถูกล็อก และช่องใดมีข้อผิดพลาด:

| สัญลักษณ์ / ชิปสี | สีพื้นหลัง / ขอบ | ความหมาย / Meaning | คำอธิบาย / Description |
| :---: | :---: | :--- | :--- |
| 🟢 | **เขียวอ่อน**<br/>(Green) | **กรอกได้ / Editable** | ช่องข้อมูลที่เปิดให้ท่านแก้ไขหรือพิมพ์ข้อความได้ตามขั้นตอนปัจจุบัน |
| 🟡 | **เหลืองอ่อน**<br/>(Yellow) | **ต้องกรอก / Required** | ช่องข้อมูลจำเป็นที่ยังว่างอยู่ ท่านต้องระบุข้อมูลก่อนจึงจะสามารถบันทึกได้ |
| 🔵 | **ฟ้าอ่อน**<br/>(Blue) | **ข้อมูลจากระบบ / System Data** | ข้อมูลที่ดึงมาจากฐานข้อมูลอัตโนมัติ (เช่น ข้อมูลพนักงาน, นโยบาย Hoshin) |
| ⚪ | **เทาอ่อน**<br/>(Grey) | **ระบบล็อก / Locked** | ช่องข้อมูลที่ระบบล็อกไว้ ไม่สามารถแก้ไขได้ (เช่น ข้อมูลของขั้นตอนก่อนหน้า) |
| 🔴 | **แดงอ่อน**<br/>(Red) | **ข้อมูลไม่ถูกต้อง / Invalid** | ช่องข้อมูลที่ไม่ผ่านการตรวจสอบ เช่น ปล่อยว่าง, ผลรวมน้ำหนักไม่ครบ 100% |

## 2. ตัวอย่างการแสดงผลในหน้าจอจริง

### 1. ช่องที่กรอกได้ปกติ (🟢 Editable)
* พื้นหลังสีขาว ขอบสีเขียว
* มีข้อความกำกับใต้ช่อง: `🟢 [กรอกได้ / Editable]`

### 2. ช่องจำเป็นที่ยังไม่ได้กรอก (🟡 Required Empty)
* พื้นหลังสีเหลืองอ่อน ขอบสีส้มทอง
* มีข้อความกำกับใต้ช่อง: `🟡 [ต้องกรอก / Required]`

### 3. ช่องที่มีข้อผิดพลาด (🔴 Validation Error)
* พื้นหลังสีแดงอ่อน เส้นขอบสีแดงเข้ม
* มีข้อความเตือน 2 ภาษาใต้ช่อง เช่น:
  ```
  ❌ กรุณาระบุเป้าหมายข้อที่ 3
  Please enter Objective 3
  ```
* เมื่อท่านเริ่มพิมพ์แก้ไขข้อมูล สีแดงจะหายไปและกลับเป็นสีเขียวทันที

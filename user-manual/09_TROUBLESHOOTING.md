## ตารางรวบรวมข้อความแจ้งเตือนและวิธีแก้ไข

| ข้อความแจ้งเตือน / Error Message | สาเหตุ / Cause | วิธีแก้ไข / Solution |
| :--- | :--- | :--- |
| **ไม่พบข้อมูลพนักงานสำหรับรหัส XXXX ในระบบ Employee Master** | พิมพ์รหัสพนักงานผิด หรือพนักงานยังไม่มีชื่อในระบบ App 53 | ตรวจสอบรหัสพนักงาน 4 หลักให้ถูกต้อง หากเป็นพนักงานใหม่กรุณาติดต่อ HR |
| **ไม่พบการตั้งค่า Routing สำหรับ Section XXXX** | ส่วนงานของพนักงานยังไม่ได้ผูกสายการอนุมัติใน App 795 | แจ้งฝ่ายบุคคล (HR) เพื่อทำการเพิ่มสายการอนุมัติของส่วนงานนั้นใน App 795 |
| **บัญชีนี้ไม่มีสิทธิ์สร้าง MBO สำหรับพนักงานใน Section นี้** | ผู้ใช้งานปัจจุบันไม่มีชื่ออยู่ในช่อง Requester ของส่วนงานนั้น | เข้าสู่ระบบด้วยบัญชีส่วนกลางของส่วนงาน หรือติดต่อ HR เพื่อขอเพิ่มสิทธิ์ |
| **พนักงานรหัส XXXX มี MBO สำหรับปี FY2026 อยู่แล้ว** | มีการสร้างเอกสาร MBO ของพนักงานท่านนี้ในปีงบประมาณนี้ไปแล้ว | ค้นหาเอกสารเดิมในหน้ารวมรายการเพื่อเข้าไปแก้ไข แทนการสร้างใหม่ |
| **ผลรวมน้ำหนักต้องเท่ากับ 100% (ปัจจุบันได้ XX%)** | ค่าน้ำหนักรวมของเป้าหมายทั้งหมดไม่ครบ 100% | ปรับตัวเลขในช่อง Weight % ของแต่ละข้อให้ผลรวมเท่ากับ 100% พอดี |
